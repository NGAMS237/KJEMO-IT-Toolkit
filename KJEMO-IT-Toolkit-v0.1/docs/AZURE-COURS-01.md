# AZURE-COURS-01

Intégration des cours Azure : 19 fiches `az` à commande directe, 5 cours avec résumé pliable, 10 schémas originaux, 4 groupes d'aide-mémoire.

## Cours
| Cours | Contenu |
|---|---|
| azure-01-02-infonuagique-azure | abonnement, collaboration, modèles de service, régions |
| azure-03-reseau-virtuel | VNet, sous-réseaux, IP, VM |
| azure-04-resolution-noms | DNS public et privé |
| azure-05-peering-routage | peering, routes système et personnalisées |
| azure-06-07-acces-prive-equilibrage | service endpoint, private endpoint, load balancer |

## Garde-fous
- Aucune fiche ne supprime de ressource ; la suppression est décrite en texte de retour arrière.
- Le stockage n'est jamais fermé sans avoir autorisé sa propre adresse d'abord.
- Les noms de ressources sont validés (nomAzure, compteStockage).

## Limites
- Rien n'a été exécuté sur un abonnement Azure réel.
- URL de sources écrites de mémoire, non ouvertes.
- Ambiguïtés AZ03-1 et AZ06-1 à confirmer avec l'enseignant.
- Hors périmètre : App Service, Application Gateway, Traffic Manager, Front Door.

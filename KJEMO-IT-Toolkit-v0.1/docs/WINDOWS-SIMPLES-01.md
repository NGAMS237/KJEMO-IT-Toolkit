## Garde-fous
Aucun mot de passe en clair ; SID pour les administrateurs ; pas de /MIR ; pas de -Force à l'extraction ; sauvegarde des droits avant takeown.

## Limites
Rien n'a été exécuté sur un poste Windows réel. Les messages affichés varient selon la langue. URL de sources écrites de mémoire.
